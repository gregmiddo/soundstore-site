# SoundStore website

The public website for SoundStore, shop management software for independent music shops and teaching studios.

It is a plain static site (no build step) published with GitHub Pages from the `main` branch.

- `index.html`: the overview, with a Music shop / Teaching studio chooser
- 13 tour pages (one feature on screen at a time; arrow keys step through them)
- `features.html`: every feature, A to Z, with a search box
- `why.html`: who it's for, how it runs, and how to book a demo

Screenshots come from the SoundStore Visual Shop Guide and show a demonstration shop with made-up figures.
